アプリによって機能と情報の取り扱いが異なります。各アプリのポリシーをご確認ください。

CSV Preflight

選択したCSVをMac内で処理。ネットワーク通信、アカウント、広告、解析、トラッキングはありません。

File Transfer Preflight

検査はMac内で完結。ネットワーク通信、アカウント、広告、解析はありません。レポートの名前・パスには機密情報が含まれる場合があります。

アプリ固有のポリシーを読む ↗

またねノート

メモは端末内に保存。入力内容を開発者のサーバーへ送信しません。課金はAppleの仕組みを利用します。

アプリ固有のポリシーを読む ↗

SIGNALS: Code Creatures

観測記録は端末内に保存。カメラ画像や元のコードを保存・送信しません。アカウント、広告、解析SDK、独自クラウドはありません。選んだ個体の情報はペアリング済みWatchへ転送します。

アプリ固有のポリシーを読む ↗

このWebサイトについて

このサイトはGitHub Pagesで配信する静的サイトです。独自の解析・広告・問い合わせフォーム・アカウント機能は設置していません。メールの送信は、お使いのメールアプリで行います。外部リンク先では、それぞれのサービスのポリシーが適用されます。
