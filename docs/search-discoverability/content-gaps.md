# File Transfer Preflight content gaps

The existing English product page accurately covers features, screenshots, limitations, privacy, and three FAQs. It has little step-by-step help for someone facing a specific delivery problem.

The original usage guide already explains profile selection, destination-root syntax, incomplete coverage, report export, and safe support requests. The gaps below concern worked troubleshooting decisions and their visibility from the portfolio, rather than claiming those reference facts are absent everywhere.

| Gap | Prepared response |
|---|---|
| What to do after a filename/path warning | [Filename and path guide](file-transfer-filename-path-guide.md): preserve originals, select the destination profile, review findings, make agreed manual changes, and recheck the final folder/ZIP. |
| Acting on the existing destination-root reference | Expand the root guidance into a handoff workflow, including what to do when the receiving location is unknown. Avoid universal service limits. |
| What to keep after a case/Unicode collision | [Collision guide](file-transfer-name-collision-guide.md): inspect all affected entries and references, distinguish necessary files meaningfully, and rescan. Similar names do not establish identical contents. |
| Follow-up after incomplete scans or changed archives | Connect the existing bounds/coverage reference to rechecking the final delivery and rebuilt ZIPs. |
| Applying the existing support-request advice | Include profile, rule ID, versions, and fictional examples in the workflow; review names/paths before sharing a report. |

The drafts address troubleshooting intent without claiming live service diagnosis, content integrity checks, automatic repair, or guaranteed transfer success. They contain no fabricated metrics or external service thresholds.

After approval, use the existing [English product page](https://chiba-yu94.github.io/portfolio-site/en/apps/file-transfer-preflight/) and [English support section](https://chiba-yu94.github.io/portfolio-site/en/support/#file-transfer-preflight) for these useful sections, with contextual links to the [original usage guide](https://chiba-yu94.github.io/preflight-tools-site/file-transfer-preflight/support/). Do not publish two competing versions of the same guidance or create keyword-variant pages. No keyword volume or ranking data was obtained.

Product claims were checked against the existing catalog and the previously captured [App Store description](https://apps.apple.com/us/app/file-transfer-preflight/id6820943200), including the decoded-cloud-root requirement and the exclusion of symbolic links/aliases.
