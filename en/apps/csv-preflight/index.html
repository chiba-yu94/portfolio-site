A SMALL TOOL FOR A REAL TASK

Find common CSV problems before an import fails.

For people preparing data imports who want to review encoding and row structure first. Open or drop a file, inspect findings by row and column, and export an issue report.

What it does

  • Inspect encoding, delimiters, quoting, and line endings
  • Find header, column-count, duplicate-row, and hidden-character issues
  • Apply optional uniqueness, required-value, character, and byte-length rules
  • Export a CSV issue report

Important limitations

  • Inspection only; no CSV repair
  • First row is treated as the header; 256 MB file limit, duplicate checks on the first 500,000 rows, and up to 10,000 reported issues
  • Does not guarantee compatibility with every importer
PRIVACY, EXPLAINED

Privacy characteristics

Selected CSV files are processed locally. No network requests, accounts, advertising, analytics, or tracking.

GOOD TO KNOW

Common questions

Does it repair CSV files?

No. CSV Preflight inspects files and exports reports. It does not automatically repair or rewrite the original CSV.

Which encodings are supported?

UTF-8 and BOM-marked UTF-16. Other encodings are reported as unsupported.

Do files leave my Mac?

Inspection is local. No account or cloud upload is needed.
